## 4. Azure translation setup: resume here

### Findings so far
- `.env.local` contains the names `AZURE_TRANSLATOR_KEY`, `AZURE_TRANSLATOR_REGION` and `AZURE_TRANSLATOR_ENDPOINT`.
- `npm run i18n:auto` reported **"No translation provider configured"**, so the values are empty or invalid.
- `npm run i18n:status` shows **1/20 locales available** (only English).
- The script reads `.env.local`, then `.env`. LibreTranslate at localhost:5000 is an optional fallback and isn't running.
- The key is only needed on the PC, not in Vercel. Translations are saved as files and pushed.

### Steps
1. Check the value lengths (this never prints the key):
   ```bash
   awk -F= '/^AZURE_TRANSLATOR_(KEY|REGION|ENDPOINT)/{print $1, "length:", length($2)}' .env.local
   ```
2. If they're empty: in portal.azure.com, open the Translator resource, go to **Keys and Endpoint**, and copy Key 1 and the Location/Region into `.env.local`:
   ```
   AZURE_TRANSLATOR_KEY=...
   AZURE_TRANSLATOR_REGION=westeurope
   ```
3. Test the key. The result should be **200**:
   ```bash
   set -a; source <(tr -d '\r' < .env.local); set +a
   curl -s -o /dev/null -w "%{http_code}\n" -X POST \
     "https://api.cognitive.microsofttranslator.com/translate?api-version=3.0&to=de" \
     -H "Ocp-Apim-Subscription-Key: $AZURE_TRANSLATOR_KEY" \
     -H "Ocp-Apim-Subscription-Region: $AZURE_TRANSLATOR_REGION" \
     -H "Content-Type: application/json" -d '[{"Text":"Hello"}]'
   ```
   | Code | Meaning |
   |---|---|
   | 200 | OK |
   | 401 | Wrong or expired key |
   | 403 | Quota used up or subscription disabled |
   | 400 | Region mismatch |
   | 000 | No connection |
4. Translate and check:
   ```bash
   npm run i18n:extract
   npm run i18n:auto
   npm run i18n:status
   npm run i18n:check
   npm run test:i18n
   ```
   If a language stays below 90% (`I18N_AVAILABLE_MIN`), run `npm run i18n:auto` again.
5. Commit and push:
   ```bash
   git add -A
   git status
   git commit -m "Translations for meeting mute guides"
   git push
   ```
   Make sure `.env.local` is never in the list.
